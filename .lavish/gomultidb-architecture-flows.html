GoMultiDB Stack

design/index.md + current package layout

A two-role distributed database prototype: `master` owns metadata and coordination; `tserver` owns query-facing and data-facing work. The dashed planned node marks the biggest unfinished integration: full query planning/execution over real tablet storage.

  • Stable layers: runtime, RPC, master control plane, tablet lifecycle, replication, transactions, storage, testing.
  • In progress: CQL gateway, SQL control, PgGate bridge.
  • Explicit gaps: production RocksDB wiring, consensus/quorum durability, durable txn coordinator state, full SQL/CQL planner.
